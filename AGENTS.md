# Project Maintenance

- The professional notebook is generated by `build_professional_notebook.py`. Preserve historical notebooks.
- Read existing code before editing. Synchronize notebook edits into the generator before rebuilding.
- After changes, run `python build_professional_notebook.py` and `python generate_documentation.py --check`.
- Run `python -m unittest discover -s tests -p "test_documentation.py" -v` for documentation changes.
- Do not manually edit generated docs or README's marked results block. Maintain explanatory prose explicitly.
- Use `verify_professional_notebook.py` for audio/split/inference checks in a prepared environment; do not run expensive training locally.
- Keep source speakers disjoint, augmentation train-only, scaling train-fitted, and test data out of model selection.
- Never fabricate metrics. Results under `results/` must come from completed Colab training/evaluation runs.
- Never publish historical notebooks with exposed tokens, raw audio, Kaggle credentials, caches, or untrusted artifacts.
